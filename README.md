# buglens-e2e

A throwaway repository used to end-to-end test **BugLens** (the PR review bot) against a
real GitHub pull request, a real LLM, and real inline comments.

Everything here is a deliberately buggy fixture. The "credential" is an obvious dummy and
matches nothing real. Do not reuse any of it.

See `buglens/docs/e2e-report.md` in the BugLens repo for the generated report and screenshots.
